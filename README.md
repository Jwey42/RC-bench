# RC-bench

A customizable RC workshop manager built as a single-file web app. Track your fleet, log maintenance, manage parts inventory, and keep bench notes — all in one place.

## Features

- **Fleet Roster** — Add and track every vehicle with scale, motor config, and status
- **Maintenance Log** — Date-stamped log of every repair, service, and mod
- **Pre-Run Checklist** — 8-point inspection before every run
- **Parts Inventory** — Log spare parts and consumables with a checkbox list
- **Bench Notes** — Freeform notepad for build ideas, tuning setups, and shopping lists
- **Dark / Light Mode** — Workshop-friendly dark mode by default with a toggle

## Usage

Open `rc-bench.html` directly in any modern browser — no server required.

Or view it live via [GitHub Pages](https://jwey42.github.io/RC-bench/rc-bench.html) once Pages is enabled.

## Setup for GitHub Pages

1. Go to **Settings → Pages** in this repo
2. Set Source to **Deploy from a branch**
3. Select **main** branch, **/ (root)** folder
4. Save — your app will be live at `https://jwey42.github.io/RC-bench/rc-bench.html`

## Tech

Pure HTML/CSS/JS — no frameworks, no build tools, no dependencies.
